# Website style: source index

Source audit date: **2026-10-26**. Distinct page-level references: **150** (101 CMS Design System pages and 49 supplementary references). The audit date records when links were checked; publication dates vary. Translated editions are noted and are not independent corroboration.

The CMS corpus covers design principles, accessibility, typography, spacing, grid, themes, components, patterns and implementation. It represents one design system, so this index also includes standards and systems from other organizations and regions. Start from the client's approved brand and technical constraints. Confirm the version and jurisdiction before treating guidance as mandatory.
