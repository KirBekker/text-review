# AI image maker

Create visual assets that fit the client's brief, brand, audience, and publishing channel. Treat generated output as a draft that needs visual and factual review.

## Before generating

Read the project brief, brand rules, approved references, and any channel specifications available in the project files or shared Drive folder. Keep client materials within the authorized project workspace. If a required decision is missing, make a reasonable reversible choice and state it briefly; ask only when the uncertainty could change the subject, rights, or business meaning of the image.

Identify:

- the image's job, audience, subject, and intended page or campaign;
- the required crop, aspect ratio, file format, text, and safe areas;
- brand colors, existing visual language, and elements that must stay consistent;
- references that define subject, composition, or style, and the role of each reference.

Use the image-generation or editing tool available in the current environment. Read [model notes and source index](references/sources.md) when model-specific controls or a source-backed choice matters. Model behavior changes; verify current parameters in the selected tool's official documentation instead of carrying over settings from another generator.

## Build the prompt

Describe the intended result in plain visual terms. Include only details that affect the image:

1. Purpose and intended placement.
2. Main subject, action, and setting.
3. Composition, crop, viewpoint, and open space needed for page copy.
4. Visual medium, materials, palette, light, and mood grounded in the client's style.
5. Exact wording, if text must appear in the image.
6. Required elements to preserve and unwanted changes to avoid.

Keep the initial prompt concise enough to review. Use a small number of references and label their roles. Prompt conventions and parameters vary by model, so check the selected generator's documentation. Use its composition, style, or subject controls when they fit the requirement.

## Generate and refine

Generate a small set of useful variations when choice matters. Inspect the actual image at full size. Check the brief, crop, visual hierarchy, subject details, hands and faces where present, brand consistency, text spelling, artifacts, and whether an edit changed anything that was meant to remain fixed.

If a revision is needed, ask for one focused change at a time and restate the critical details to preserve. For diagrams, product details, prices, labels, or other factual visuals, verify every visible claim against the supplied source. Correct small production-critical text in a design editor when the image model cannot render it reliably.

## Rights and delivery

Create original visual directions. Avoid close imitation of a living artist, protected character, logo, or competitor's distinctive brand treatment. Use a real person's likeness only when the brief supplies an authorized reference or the user confirms permission. For commercial work, check the selected generator's current usage terms. Those terms do not guarantee legal clearance for every output.

Deliver the final image with a short note naming its intended use, dimensions or format when known, and any visible limitation that affects publication. For website assets, provide a descriptive filename and useful alt text when requested or when they are part of the content handoff. Use empty alt text for images that are decorative in their page context.
