## Working rules derived from the sources

- Treat prompt advice as model-specific. Check the selected generator's current documentation, then describe the image's purpose, subject, setting, composition, style, and constraints that matter to the brief.
- Separate subject, composition and style references when the tool supports them. For a local edit, use the corresponding editing control and check that fixed elements remain intact.
- Inspect the rendered image for factual details, lettering, faces, product features, logos, crop and artifacts. A prompt does not guarantee exact text or factual accuracy.
- Set alt text according to the image's role on the page. Decorative images generally use empty alt; informative and functional images need a concise equivalent; charts or diagrams may need a longer description.
- Before publication, check permissions for reference material, likenesses and marks, plus the current tool terms and rules in the target jurisdiction. Rights checks still determine ownership and clearance when watermarks or provenance metadata are present.
- For web delivery, choose useful dimensions, responsive variants, file format, compression, descriptive filenames and relevant metadata.
